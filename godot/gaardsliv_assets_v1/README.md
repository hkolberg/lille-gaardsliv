# Gårdsspillet assets v1

Logical isometric tile footprint: 64×32 px (2:1).
Tile sprite canvas: 96×72 px, transparent, bottom-center anchor.
Props: 96×112 px, transparent, bottom-center anchor.

Layers:
1. terrain
2. roads/plazas/water
3. fences/gates
4. props

N/E/S/W reference points are stored in meta/manifest.json and shown in meta/master_tile_64x32.png.

This is the first normalized game-ready extraction from the approved visual atlas. The source atlas was AI-generated, so visual seams should be reviewed in-engine before treating the artwork as final production art.
