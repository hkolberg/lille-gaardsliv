# Gårdsspillet straight shoreline edges v1

This package contains four single-side straight shoreline assets.

They are intended to cover the long flat slanted sides of lakes and rivers in the isometric grid.

Files:
- water/straight_edges/water_edge_nw.png
- water/straight_edges/water_edge_ne.png
- water/straight_edges/water_edge_sw.png
- water/straight_edges/water_edge_se.png

Technical target:
- logical footprint: 64x32
- canvas: 96x72
- anchor: bottom-center
