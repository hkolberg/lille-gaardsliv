# Gårdsspillet water inner points v2

Direct PNG assets for the four visual outer shoreline points.

These replace the previous runtime masking approach. The approved artwork has
been normalized to the game's 64x32 logical isometric diamond and stored on
the established 96x72 transparent sprite canvas.

Design target:
- about 1/6 visible land
- about 5/6 water
- much shallower land protrusion than v1
- four direct N/E/S/W assets; no runtime-generated north variant
