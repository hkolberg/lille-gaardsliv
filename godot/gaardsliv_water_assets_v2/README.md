# Gårdsspillet water asset pack

This package contains individual transparent PNG assets extracted from the provided water tile atlas.

Folders:
- water/base
- water/shores
- water/variants
- meta

Technical target:
- logical tile footprint: 64x32
- sprite canvas: 96x72
- anchor: bottom-center

Important:
The shoreline direction names are a first-pass packaging. Verify orientation in-game before wiring all rules permanently.
