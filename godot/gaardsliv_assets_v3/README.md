# Gårdsspillet assets v3

V3 is the visual replacement for the simplified v2 repair set.

Visual source:
- approved initial v2 concept sheet for roads, water, fences and gates
- approved detailed pine/forest concept sheet

Technical standard:
- logical isometric tile footprint: 64×32 px
- tile sprite canvas: 96×72 px
- prop sprite canvas: 96×112 px
- transparent PNG
- bottom-center anchor

Important:
The source artwork is AI-generated. Orientation naming has been normalized as far as possible,
but every road/fence/gate variant must be visually verified in-engine before old fallbacks are removed.
