# Gårdsspillet assets v4

This pack contains the v4 plaza and water tile assets for Gårdsspillet.

Style target:
- Settlers-inspired hand-painted isometric strategy game look
- warm countryside palette
- clean transparent PNG sprites

Technical target:
- logical footprint: 64×32 px
- tile sprite canvas: 96×72 px
- anchor: bottom-center

Included:
- plazas: base, 2 variants, 4 edges, 4 outer corners
- water: center variants, edges, outer corners, inner corners, decorated shores, ford/crossings

Additional note:
- includes `water_center_plain.png`, a clean open-water tile with no extra content.
